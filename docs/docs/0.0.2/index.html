producer · broker · consumer 세 모듈의 기능, 설정, 사용 예제, API 레퍼런스를 한 곳에 모았습니다. 왼쪽 사이드바 또는 아래 카드에서 시작할 모듈을 골라 주세요.

모듈

각 모듈은 Spring Boot 애플리케이션에 의존성으로 추가하는 라이브러리입니다. core는 공통 타입을 제공하며, producer · broker · consumer는 각각의 애플리케이션에 따로 추가해 사용합니다.

core
모든 모듈이 공유하는 핵심 타입을 정의합니다. 메시지, 토픽, 응답 등 도메인 원시 타입을 모아둡니다.
producer
메시지를 broker로 보내는 모듈입니다. 동기로 동작하며, 전달에 실패하면 자동으로 재시도합니다.
broker
메시지를 디스크에 보관하고 consumer에게 전달하는 모듈입니다. 토픽 패턴에 따라 분배합니다.
consumer
broker가 보낸 메시지를 토픽 패턴이 맞는 핸들러로 라우팅하는 모듈입니다.
