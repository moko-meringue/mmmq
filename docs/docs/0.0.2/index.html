모듈

mmmq는 세 개의 모듈로 구성되어 있습니다. 각 모듈은 독립적으로 의존성에 추가하여 사용할 수 있습니다.

producer
메시지를 보내는 클라이언트입니다. 빌더로 재시도 정책을 설정하고, ProduceException으로 실패를 알립니다.

broker
메시지를 디스크에 저장하고 Dispatcher로 라우팅합니다. TopicQueue, 세그먼트, 체크포인트, DLQ가 포함됩니다.

consumer
@MMMQListener와 MMMQListener<T> 두 가지 방식으로 핸들러를 등록합니다. 패턴 매칭과 ACK/NACK는 자동입니다.
