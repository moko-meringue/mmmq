5.13

Callout

참고 / 주의 / 팁 3종. 좌측 컬러 바.

참고
메시지 노출 경계는 인덱스 파일의 fsync가 끝난 시점입니다. 데이터 파일만 fsync해서는 충분하지 않습니다.
주의
Dispatcher 이름은 체크포인트 파일명으로 사용되므로 [A-Za-z0-9._-]+ 패턴만 허용됩니다.
팁
오프셋 인덱스에 fsync까지 끝난 메시지만 Dispatcher에게 노출됩니다.
