# MMMQ (Moko-Meringue's Message Queue)

MMMQ는 메시지 큐 시스템의 핵심 개념과 동작 원리를 학습하기 위해 만든 Spring Boot 기반 메시지 큐 라이브러리입니다. JitPack을 통해 배포됩니다.

## 문서

|---|---|
| 빠른 시작 | [mmmq.org/quickstart.html](https://mmmq.org/quickstart.html) |
| 레퍼런스 문서 | [mmmq.org/docs](https://mmmq.org/docs/) |
| 릴리스 | [mmmq.org/release.html](https://mmmq.org/release.html) |
